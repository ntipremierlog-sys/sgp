# Módulos Salvos para Continuidade Futura

Estes arquivos contêm a implementação completa dos módulos de:
1. **Relatórios e Medição** (`relatorios-page.original.tsx`)
   - Memória de Cálculo Mensal (MC)
   - Boletim de Medição (BM)
   - Apuração de glosas e faturamento
   - Exportação XLSX / PDF

2. **Fechamento Mensal** (`fechamento-page.original.tsx`)
   - Rotina formal de encerramento da competência (ciclo 10 ao 09)
   - Congelamento de snapshots imutáveis (SHA-256)
   - Homologação Petrobras e auditoria

### Motivo da Preservação
Estes módulos foram temporariamente retirados da visualização dos usuários a pedido da gestão, para que no momento os usuários vejam apenas o símbolo de construção. Quando a apuração por vaga for integrada às fórmulas financeiras e de faturamento, estes arquivos servirão de base para a continuidade do desenvolvimento.
